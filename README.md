# 悦森盒 YueDen

版本：**1.0.3** · Windows x64 发布包

悦森盒 YueDen 是一款 Windows 桌面应用，用来统一管理个人本地影视、番剧、音频、书籍、漫画和游戏资源。它把分类筛选、封面浏览、媒体播放、阅读、游戏存档快照与 WebDAV 同步放在一处，方便查看资源和备份状态。

## 部分快捷操作
- 双击**ESC**快速最小化所有窗口并暂停、静音、启动伪装模式，自动跳转到B站播放BV1Kq3s65EzA。
- **右键**：关闭窗口；播放列表排序；资源卡片快速修改；更换高亮、下划线；
- 筛选模式下，勾选框上左键拖动进行快速选择。

## 1.0.3 WebDAV 同步收尾

- 移除“重置同步数据”操作，设置页保留连接测试和同步入口。
- 云端存档索引缺少可用条件写入标识时，重新读取并核验后再写入；写入后回读验证。
- 存档数据块、清单和云端目录分阶段确认。任一步失败时快照继续显示“待同步”，可从条目或设置页重试。
- 设置页同步仅在云端目录和资源库提交确认后更新快照状态；部分失败会提示并刷新状态。
- 重新打开同步对照时保留仍有效的逐项选择；已变化或消失的资源会清除旧选择。

## 1.0.3l WebDAV 同步修复

- `sync-state.json` 使用 gzip 存储，保留完整资源和共同基线；按当前 97 项数据估算，从约 878 KB 降至约 149 KB。
- GET 正文因 socket 中断时，最多完整重读两次；每次确认强 ETag 未变化，并使用独立新连接，不使用 Range。
- 正文读取失败日志记录已收字节、预期字节和 ETag。
- 本次同步对照逐项显示本地、云端最后修改时间（本地时区、精确到秒）；时间仅供人工查看，不替代内容 revision 判断。

## 1.0.3k WebDAV 同步修复

- 本地与云端存在差异时，先显示可点击的本地、云端、合并选择，再执行同步；合并中的未决冲突继续逐项确认。
- 上传只处理本次新增的封面哈希；未变化封面不发请求，内容寻址对象使用条件创建，已存在时跳过。
- 当资源库与云端索引未变化时，只检查轻量级远端校验信息，不读取同步状态、存档清单或对象文件。
- 已知未变化的存档数据块直接复用目录索引证明；新数据上传成功后不再额外下载整份内容，只有请求中断时才回读确认。
- 本地新建、备注修改和删除存档会增量更新本机目录缓存，下一次同步不必重新扫描所有存档清单。

## 1.0.3 更新

## 源码结构

- `app/`：Electron 主进程、preload、主界面、资源管理和阅读器。
- `app/player/src/`：TypeScript 播放服务、mpv 后端及窗口管理。
- `app/player/native/`、`app/native/`：原生窗口和文件选择器源码。
- `app/assets/`：应用及任务栏图标。
- `app/vendor/`：网页第三方组件及许可。
- `tests/`、`app/player/tests/`：测试源码；部分集成测试需额外运行时和本地测试媒体。
- `packaging/Launcher.cs`、`app/player/build-release.cjs`：启动器及现有发布脚本。
- `SOURCE-MANIFEST.json`：源码 SHA-256 与发布包对应检查记录。

## 开发与构建

需要 Node.js、pnpm、Windows x64、.NET Framework 4.x 编译器及 Electron **44.3.0**。播放器依赖已锁定：

```powershell
cd app/player
pnpm install --frozen-lockfile
pnpm build
pnpm test
node native/build.cjs
```

独立开发入口：`node app/player/start-isolated.cjs <Electron可执行文件绝对路径>`，使用 `app/player/dev-user-data`，避免连接正式数据。

完整运行还需要在原位置提供 ResourcePicker、mpv、FFmpeg 等组件，可从本版本 Windows 发布包取得。不要覆盖正式安装或个人数据。

现有完整打包脚本依赖仓库上一级的 `runtime-44/extracted`、`branding-tools`、`third-party-source`、`packaging/第三方组件.md` 及应用内原生/媒体运行组件。目前不是下载仓库即可一键打包的独立构建流程。源码上传保留现有实现，未重构或重新打包程序。
