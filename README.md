# 悦森盒 YueDen

悦森盒是一款面向 Windows 的个人数字资源管理软件，帮助你把分散在本地的影视、番剧、音频、书籍、漫画和游戏整理到一个资料库中。你可以搜索和筛选资源，为条目补充封面、评分、笔记与进度，也可以在软件内播放、阅读和管理游戏存档快照。

## 软件功能

- **统一管理本地资源**：按资源类型浏览，使用标签、分类、状态、评分等条件筛选。
- **补充作品资料**：使用可用的元数据来源匹配作品信息和封面，并在条目中继续编辑。
- **播放与阅读**：在软件内播放视频和音频、阅读书籍，并记录进度。
- **管理游戏记录**：记录发行平台、游玩平台和状态，识别存档路径、创建存档快照，并可通过 WebDAV 同步。
- **备份资料库**：导出本地备份，保存资源库和设置；也可按需配置 WebDAV。
- **自定义体验**：设置主题、强调色、默认页面和伪装模式。

## 常用操作

- **快速进入伪装模式**：在设置中启用伪装模式后，快速连续按两次 `Esc`。按 `Ctrl` + `Shift` + `U` 可退出或切换伪装模式。进入时会静音并最小化应用窗口、关闭播放器；填写了伪装视频链接时还会打开该链接。
- **右键卡片快速编辑**：在资源卡片的名称、标签、分类、游戏平台或状态等区域右键，可以直接修改对应内容，不必先打开条目编辑器。
- **平台状态循环**：在条目编辑器或卡片快速编辑中点击游戏平台，依次切换“未指定 → 发行平台 → 我玩过 → 未指定”。
- **批量编辑资源**：在页面点击“筛选”进入筛选/选择模式，勾选资源后使用批量工具，可批量编辑状态、游戏平台、标签和分类，也可刷新、删除或处理游戏存档。
- **查看和处理存档快照**：游戏页面的“存档”条件可筛选有存档或未关联存档的游戏。切换到列表布局后可查看快照和同步状态；未关联快照还会显示备份时记录的路径，并可关联到资源。进入筛选/选择模式后可以勾选资源或单个快照。选中游戏后，批量存档工具提供“获取路径”和“备份”两项操作；配置了 WebDAV 后，本地备份会自动尝试上传。

## 下载与运行

从 [GitHub Releases](https://github.com/Fyansher/YueDen/releases/latest) 下载 Windows x64 压缩包，完整解压后运行根目录中的 `YueDen.exe`。升级时请将新版本解压到原目录并保留 `user-data` 文件夹，这样已有资料库和设置可以继续使用。

## 数据说明

资料库和设置保存在本机应用数据目录中。WebDAV 是可选功能；使用前请在设置中填写服务器信息并测试连接。公开发布包不包含个人资料库、登录凭据或本机日志。

## 项目结构

- `app/`：桌面应用、资源管理界面和元数据功能。
- `app/player/`：播放器服务、阅读器及其相关实现。
- `tests/`：项目测试。
- `packaging/`：Windows 启动器相关文件。
