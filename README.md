# 悦森盒 YueDen

悦森盒是一款面向 Windows 的个人数字资源管理软件，帮助你把分散在本地的影视、番剧、音频、书籍、漫画和游戏整理到一个资料库中。你可以按类型、标签、分类和状态浏览资源，也可以为条目记录封面、评分、笔记与进度。

## 软件功能

- **统一管理本地资源**：整理影视、番剧、音频、书籍、漫画和游戏，支持搜索、筛选、分类与自定义标签。
- **补充条目信息**：通过可用的元数据来源匹配作品信息和封面，并可在条目中继续编辑。
- **播放与阅读**：在软件内播放视频和音频、阅读书籍，并保存相关进度。
- **管理游戏记录**：记录游戏平台、状态和游玩时间，也可为游戏存档创建快照。
- **备份与同步**：导出包含资料库和设置的本地备份；也可按需配置 WebDAV 同步。
- **自定义使用体验**：支持主题、强调色、默认页面和伪装模式等设置。

## 下载与运行

从 [GitHub Releases](https://github.com/Fyansher/YueDen/releases/latest) 下载 Windows x64 压缩包，完整解压后运行根目录中的 `YueDen.exe`。升级时请将新版本解压到原目录并保留 `user-data` 文件夹，这样已有资料库和设置可以继续使用。

## 数据说明

资料库和设置保存在本机应用数据目录中。WebDAV 是可选功能；在使用前请先配置并测试自己的服务器连接。软件的发布包不包含个人资料库或账号数据。

## 项目结构

- `app/`：桌面应用、资源管理界面和元数据功能。
- `app/player/`：播放器服务、阅读器及其相关实现。
- `tests/`：项目测试。
- `packaging/`：Windows 启动器相关文件。
