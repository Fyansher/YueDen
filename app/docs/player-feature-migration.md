| 原能力 | 当前状态 |
|---|---|
| 影视/番剧独立旧播放器入口 | 已替换为统一服务；共享书籍/漫画/文档阅读器保留 |
| 声音主界面引擎与独立展示窗 | 主界面换为控制适配器，无audio元素；旧声音窗口创建入口转向统一播放器 |
| 指定音轨、成员与稳定歌单引用 | 仍按resourceId/memberId引用；播放列表编辑不修改原歌单或资源库 |
| 视频进度 | 新服务回写共享reader-progress-store，按资源及文件键保存；尚待更多真实分集回归 |
| 声音旧进度与书签 | 初步迁移至player-state，旧数据备份及原文件保留；界面备注、跳转和删除已实现，尚待实际完整回归 |
| 停止与续播 | 停止归零保留队列；新会话模型测试通过；整部资源最后成员选择仍需完善验证 |
| 音乐/音声独立上下文 | 保存与恢复本地引用已实现；各分区播放模式等细节的完整迁移仍待核对 |
| 顺序/循环/随机 | 已有主进程操作和UI；音声限制顺序；复杂上下文切换尚未验收 |
| 睡眠、自定义分钟、轨末停止 | 已实现；未执行长时定时或重启相关人工测试 |
| 字幕、倍速、当前音轨 | mpv控制与UI已接；尚未用真实字幕/多音轨样本全面验收 |
| 本地同名/手选LRC | 复用旧解析器，新异步代次保护；UTF-8及带BOM UTF-16；不自动联网 |
| 旧缓存/用户编辑歌词、音轨偏移 | 文件保留，但统一窗口尚未完整接入旧缓存优先级及偏移设置；明确未完成 |
