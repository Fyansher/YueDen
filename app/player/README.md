# 悦森盒 YueDen

正式版本：1.0.1 · Windows x64

悦森盒 YueDen 是一款用于集中整理、浏览、播放和阅读个人影视、番剧、音频、书籍、漫画等本地数字内容的 Windows 桌面应用。

## 1.0.1 本次发布

Windows 音量面板中的播放器会话显示 YueDen 和软件图标；设置页红色清除缓存区与导出备份垂直对齐；媒体播放器任务栏缩略图增加上一项、播放/暂停、下一项按钮，复用既有单mpv播放会话。

沿用1.0.0的P1-A快照缓存和限定联网缓存清除功能。P1-B尚未实施，内部标识、库格式、旧安装及个人数据保持不变。mpv二进制未修改、升级或重新下载，仅设置运行时音频会话名称及图标。

## 本版调整

总览“阅读、游玩与播放”改为“时长统计”，按游戏、影视、番剧、漫画、书籍、声音六类显示。环形图位于左侧，旁边可点击分类；右侧上下分别显示最近使用和时长最长的最多五项资源。封面与名称同行并靠近中轴，时长条位于右侧。悬停环形分区或点击分类可切换排行，分区轻微放大加深，条形生长与名称封面弹入；尊重关闭动效和系统减少动态效果设置。

统一播放器接入分资源计时，按当前资源 ID 区分窗口前台使用与实际播放，重叠部分只累计一次；辅助窗口不重复计时。暂停且不在前台、停止或关闭后不计时，切换资源后不再累计到上一项。拖动进度不会把跳过的媒体长度算成使用时长。休眠或进程长时间挂起（采样间隔超过10秒）不补算该间隔。

书籍和漫画按各自资源累计前台阅读时间，切换/失焦/关闭时结算，退出前等待落盘。阅读时长字段自动补齐空值或“本机记录”值，已有手动值（包括0）和旧的非空未标来源值不覆盖；用户编辑自动值后即转为手动。原始秒数保存在既有 usage-records.json，自动小时值在读取资源库时投影，避免计时频繁改写资源库；用户保存条目时沿用现有字段持久化。小时输入步长0.1，统计显示一位小数。自动显示的不足0.05小时为0.0h，但秒数保留。

游戏继续使用已有手填/平台累计时长，不新增外部游戏进程监控。各资源已有填写/平台值与本机记录取较大值，避免相加重复。只有关联资源库条目的播放才归属到分类；未关联资源的临时文件不分摊给其他资源。

保留2.25.40的豆瓣简介、tstrs/1lib公开书籍源、设置排版和双Esc伪装修复。既有1lib/豆瓣电影验证页阻挡、外部浏览器自动播放与跳转未端到端验收等限制不改写为通过。

## 启动

完整解压 YueDen-1.0.1-Windows-x64.zip，双击根目录 YueDen.exe。必要的 Electron 44.3.0、mpv、FFmpeg 和原生桥随包提供，不依赖系统 PATH、预安装 mpv/FFmpeg、node_modules 或开发工具。系统需支持 Electron 44，并提供 Windows .NET Framework 4.x。

本版包含导入元数据流程修复：移除“暂停元数据获取”，获取期间可点击“导入所选资源”停止未完成请求并导入，保留已取得资料；联网选项、添加文件和全选均正确启动查询。QQ 音乐、网易云、酷狗公开元数据默认启用，移除多余开关。

新增 SeedHub 影视与番剧公开元数据来源，仅采集资料字段。既有真实普通样本测试取得电影 3 条、动漫 1 条；不保证所有作品都有结果。Jikan 最近实测仍为上游 HTTP 504，客户端保留其他来源并明确显示故障，不标为已恢复。

沿用上一版 WebDAV 修复： 首次同步、连接测试误报成功和备份随机数错误。InfiniCLOUD 请使用账户提供的 WebDAV 地址（例如 https://ogi.teracloud.jp/dav/）、连接 ID 和应用专用密码；仅填写该服务根地址时自动补齐 /dav/。首次同步逐级创建目录，保留同步前备份、ETag 条件写入和冲突保护。网络请求有明确超时，HTTP、认证、限流和上游故障分别显示。本轮使用本地真实 HTTP 服务验证，尚未使用个人 InfiniCLOUD 账户验证。

修复浅色主题在播放器、辅助窗口和旧声音窗口的继承问题，统一悬停文字颜色，加强全成就卡片金色边框；书籍、漫画和主窗口弹窗也已检查。

沿用上一版播放器每次打开的位置和尺寸偏移修复，关闭前保存四窗布局及最大化/全屏状态；同一显示器和缩放使用实测边界恢复，显示器变化时保留可见范围保护。声音页面的歌曲、歌单及歌单内歌曲支持拖动和 Alt + 上下键排序；移除歌单成员上下按钮。歌曲排序只改变展示顺序，不改专辑曲序；歌单成员使用既有稳定引用保存。

同时包含上一轮阅读器主题缺失和“移动到分类”下拉框修复。

沿用的主窗口底部播放状态栏包含的封面、歌名、艺术家、音量、静音与四态播放模式；标题区域固定宽度并省略长文本，播放控件位置不受歌名长度影响。所有控件连接同一播放会话。

影视/番剧播放时，播放列表使用“队列、影视、番剧”，直接读取主窗口资料库的本地视频文件。多文件合集默认折叠并显示第一项，单文件直接显示；资源双击播放，右键分类按钮可按名称升序、降序或随机排序，保留合集和内部文件拖动排序。切回声音后恢复原声音分类。列表顺序只影响播放器展示，不改写资料库和文件。

“睡眠分钟”和“书签备注”输入框使用应用主题。媒体播放区域支持左右键每次1秒、上下键每次1%音量，按住重复触发且在松开前生效；滚轮调节音量，双击切换暂停/播放。音频网页区域和原生视频子窗口均支持，包括全屏。编辑输入框、下拉框和对话框时保留其原操作；标题栏双击仍用于窗口最大化。Ctrl/Alt/Shift/Win组合键不作为普通播放器方向键处理。

保留2.25.34的双语歌词、混合歌单、排序滚动位置及末项循环修复。没有更换mpv、升级依赖、改写资源库或原始媒体。

用户原黑屏视频的首次播放、调整窗口、全屏进出、音频切回视频、拖动进度后继续显示五项历史人工复验全部通过；此历史结果保留，不冒充本版新的人工验收。

## 数据兼容与升级

便携数据继续使用程序根目录的 user-data，内部应用ID com.unifiedmanager.redesign、包标识 unified-manager-desktop、数据库/配置文件名、协议和迁移键均保留。新旧启动器名称均可识别，不按 YueDen 品牌另建配置库。

独立解压目录不会自动读取其他安装目录的数据，这是原有便携行为。保留原安装和数据备份；需要在新目录验证旧库时，关闭旧程序，将完整 user-data 的副本放在新包根目录，再运行 YueDen.exe。不要只复制 library.json，否则设置、播放记录、歌单、书签等相关文件可能缺失。此发布过程不覆盖原安装、不移动或修改个人数据。
